# 🤖 AI FAQ Chatbot

An AI-powered FAQ chatbot built using Python, Natural Language Processing (NLP), TF-IDF vectorization, cosine similarity, and Streamlit.

## 🚀 Features

- Answers frequently asked questions
- Uses NLP to understand user questions
- Finds the most relevant FAQ using TF-IDF
- Uses cosine similarity for question matching
- Shows match confidence
- Rejects unrelated questions
- Simple and user-friendly web interface

## 🛠️ Technologies Used

- Python
- Streamlit
- Scikit-learn
- Natural Language Processing (NLP)
- TF-IDF
- Cosine Similarity
